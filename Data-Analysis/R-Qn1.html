Setting up a for loop, that repeats for 1 to “N”(10000) times.

Within the loop, “Xprev <- samples[i - 1]”is used to retrieve the most recent sample from the list of samples.“Xstar <- rnorm(1, mean = Xprev, sd = s)”is used to generate a new sample from a normal distribution centred(“mean”) at Xprev and, with a standard deviation(“sd”) of s.

Within the loop, “log_r <- log(f(Xstar)) - log(f(Xprev))”is used to compute the acceptance ratio between the proposed sample(“Xstar”) and the most recent sample(“Xprev”). The question provides the log formula to avoid numerical errors.

Within the loop, “u <- runif(1)”is used to generate a random number u from the uniform distribution between 0 and 1.

Otherwise, the “else” statement(“samples[i] <- Xprev”) adds the previous sample back into the list again.

Lastly, the function “return(samples)” returns the array of samples generated.

metropolis_hastings <- function(Xo, N, s) {
    samples <- numeric(N)
    samples[1] <- Xo
    
    for (i in 2:N) {
        Xprev <- samples[i - 1]
        Xstar <- rnorm(1, mean = Xprev, sd = s)
        
        log_r <- log(f(Xstar)) - log(f(Xprev))
        
        u <- runif(1)
        
        if (log(u) < log_r) {
            samples[i] <- Xstar
        } else {
            samples[i] <- Xprev
        }
    }
    
    return(samples)
}
